# Security

## Audits

Tacit's v1 release was reviewed in three audits:

- [Fable 5.1 lock checkpoint](./audit/AUDIT-2026-09-16-17-fable51-lock-checkpoint.md), the review that gated the deploy.
- [External automated review](./audit/AUDIT-2026-09-21-gpt-astra-external-review.md).
- [Pashov `solidity-auditor` v4 round](./audit/AUDIT-2026-09-24-pashov-solidity-auditor-v4.md), a 24-agent review run
  after deployment that extended to the zkVM guest.

The full review history is in [audit/AUDITS.md](./audit/AUDITS.md).
